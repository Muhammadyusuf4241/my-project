# 📱 Zamonaviy HTML/CSS/JS Kalkulyator

Zamonaviy dizayn, qulay interfeys va boy funksionallikka ega bo'lgan kalkulyator veb-ilovasi.

## ✨ Xususiyatlari

- 🧮 **Asosiy arifmetik amallar:** Qo'shish (+), Ayirish (−), Ko'paytirish (×), Bo'lish (÷).
- 🔄 **Qo'shimcha funksiyalar:** Foiz hisoblash (%), Ishorani o'zgartirish (±), Bitta raqamni o'chirish (DEL), To'liq tozalash (AC).
- 🌓 **Mavzular (Theme):** Qorong'i (Dark) va Yorug' (Light) rejimlar o'rtasida o'tish (foydalanuvchi tanlovi saqlanib qoladi).
- ⌨️ **Klaviatura yordamida boshqarish:** Raqamlar, amallar, `Enter`, `Backspace`, `Escape` tugmalari to'liq ishlaydi.
- 📱 **Moslashuvchan (Responsive) dizayn:** Mobil qurilmalar va kompyuter ekranlariga to'liq moslashgan chiroyli Glassmorphism dizayn.
- 🎯 **Aniqlik:** Kasr sonlar bilan ishlashdagi hisoblash xatolarining oldi olingan.

## 🚀 Qanday ishga tushirish mumkin?

1. Loyihani brauzerda ochish uchun shunchaki [index.html](file:///home/runner/work/my-project/my-project/index.html) faylini istalgan brauzerda (Google Chrome, Firefox, Safari va h.k.) oching.
2. Yoki VS Code dasturidagi **Live Server** kengaytmasi orqali ishga tushirishingiz mumkin.

## ⌨️ Klaviatura tugmalari

| Tugma | Vazifasi |
|---|---|
| `0 - 9` | Raqamlarni kiritish |
| `+`, `-`, `*`, `/` | Arifmetik amallar |
| `Enter` yoki `=` | Natijani hisoblash |
| `Backspace` | Oxirgi kiritilgan raqamni o'chirish (DEL) |
| `Escape` yoki `C` | Hammasini tozalash (AC) |
| `.` yoki `,` | O'nlik nuqta qo'yish |
| `%` | Foizni hisoblash |
